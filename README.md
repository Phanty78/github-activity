# github-activity

## Description

This repository is part of the exercises provided by the roadmap.sh website.
https://roadmap.sh/projects/github-user-activity
This program runs exclusively in the terminal and displays the latest events for a GitHub profile.

## Setup

To install dependencies:

```bash
bun install
```

## Usage

To use it, simply type `bun github-activity <profile>`, where `profile` is the name of the account whose events you want to view.

bun github-activity phanty78
